# Ceci The Brave: web test build

A **development test build** of Ceci The Brave for trying the game in a browser (desktop or phone). It is not the release.

- Play: https://aldorosenfeldjr.github.io/Ceci_The_Brave_WebTest/
- Engine: Godot 4.6 (Web export, single-threaded, Compatibility renderer).
- Controls: keyboard, Xbox / PS5 controllers (USB or Bluetooth) and on-screen touch buttons on phones (play in landscape).
- **Dev mode is ON** (title screen → MODO DEV): pick any level, invincibility, touch-control preview.
- Progress is stored in your browser; clearing site data resets it.
- Audio starts after your first tap/key press (browser rule).

Art: GrafxKid (CC0) · Font: Press Start 2P (SIL OFL) · Music and sound effects generated in code.
